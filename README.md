# mydesk-tests

Автотесты для **MyDesk**. Это моё личное приложение-«рабочий стол» на Electron + Node.js + PostgreSQL (PGlite): электричество, финансы, работа, обучение, английский и раздел «Качество».

**Стек:** Playwright · TypeScript · Page Object Model · UI- и API-тесты · GitHub Actions · Allure · свой репортер.

## Что внутри

```
src/
  api/MyDeskApi.ts        клиент REST API (одна сессия = одно «устройство»)
  pages/                  Page Objects: Login, Home, SpendModal, Quality, BasePage (меню, заголовок, модалки)
  fixtures/test.ts        фикстуры: api, adminApi, newUser (новый приглашённый пользователь), userPage
  data/                   тестовые пользователи и билдер прогонов
reporters/mydesk-reporter.ts   свой репортер → отправляет итоги прогона в MyDesk «Качество»
tests/
  setup/auth.setup.ts     первый аккаунт на пустой базе = админ, сессия сохраняется в .auth/
  api/                    health, авторизация (401/403/409, лимит устройств, инвайты), документы, приём результатов
  ui/                     вход, навигация по всем разделам, быстрый расход (UI → проверка через API), «Качество»
```

## Как запускается

Каждый прогон поднимает **свой** сервер MyDesk из исходников (`MYDESK_APP_DIR`, по умолчанию `../MyDesk`). У этого сервера **пустая временная база** и временная папка бэкапов, поэтому тесты никогда не трогают настоящие данные и не зависят друг от друга.

```bash
npm ci
npx playwright install chromium
cp .env.example .env          # при необходимости поправить пути
npm test                      # все тесты
npm run test:api              # только API
npm run test:smoke            # @smoke
npm run report                # HTML-отчёт Playwright
npm run allure                # Allure Report (нужен allure CLI)
```

## Отчёты

- **Playwright HTML.** Трейсы, скриншоты и видео (в CI) упавших тестов.
- **Allure.** Результаты лежат в `allure-results/`, в CI сохраняются как артефакт.
- **MyDesk «Качество».** Если в `.env` заданы `MYDESK_URL` и `MYDESK_QA_KEY` (ключ берётся в «Качество → Подключение»), итоги прогона уходят в приложение. Там есть pass rate, нестабильные тесты, самые медленные тесты, матрица «тест × прогон» и запуски GitHub Actions.

## CI

`.github/workflows/tests.yml` запускается на каждый push, на PR и раз в сутки ночью. Тестируемое приложение лежит в приватном репозитории, поэтому нужен секрет `MYDESK_REPO_TOKEN`: fine-grained token с доступом *Contents: read* к `Mcsim97/mydesk`.

## Баги, которые нашли эти тесты

| # | Что | Как нашли | Статус |
|---|-----|-----------|--------|
| 1 | `PUT /api/store/<doc>` принимал любой JSON (строку, число, массив) и заменял им весь документ пользователя, после чего раздел ломался | API-тест «битый JSON → 400» вернул 200 | исправлено, регрессионные тесты в `store.api.spec.ts` |
| 2 | Гонка роутера: Главная после `await` дописывала разметку в общий `#view` поверх уже открытого раздела, и в «Электричестве» появлялась «Ошибка модуля» | UI-тест навигации падал примерно в 1 из 10 прогонов под нагрузкой (`--repeat-each`) | исправлено (новый `#view` на каждый переход), тест стабилен на 3×139 прогонах |
